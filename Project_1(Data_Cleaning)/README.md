
# Project 01: Data Cleaning and Preparation

## Overview
This project is part of my Data Analytics Internship at DecodeLabs. The main objective is to inspect, clean, and prepare raw data to make it accurate, consistent, and suitable for further analysis.

Data cleaning is an essential step in the data analytics process because the quality of data directly affects the reliability of analytical results.

## Objectives
- Understand and inspect the raw dataset.
- Identify missing and null values.
- Detect and handle duplicate records.
- Identify and correct data inconsistencies.
- Standardize data formats and column names.
- Prepare a clean dataset for further analysis.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Microsoft Excel

## Project Workflow

### 1. Data Loading
Imported the dataset into Python using Pandas.

### 2. Data Inspection
- Checked dataset dimensions.
- Reviewed column names and data types.
- Examined sample records.
- Identified missing values and duplicates.

### 3. Data Cleaning
- Handled missing values where necessary.
- Removed duplicate records where appropriate.
- Corrected inconsistent data formats.
- Standardized column names.
- Checked data types and corrected them where required.

### 4. Data Validation
Reviewed the cleaned dataset to ensure that:
- Missing values were handled appropriately.
- Duplicate records were addressed.
- Data types were consistent.
- The dataset was ready for further analysis.

### 5. Exporting Cleaned Data
Saved the cleaned dataset in Excel format for future analytical tasks.
