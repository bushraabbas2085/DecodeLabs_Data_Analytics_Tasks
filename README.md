## Internship Projects

### 1. Project 1 – Data Cleaning & Preparation

**Objective:**  
To inspect, clean, validate, and prepare raw data for further analysis.

**Description:**  
This project focuses on identifying data quality issues and preparing a structured dataset suitable for analysis. Different data validation and cleaning techniques were applied using Python.

**Key Tasks:**
- Load and inspect the raw dataset.
- Identify missing and null values.
- Check duplicate records and duplicate IDs.
- Examine data types and column formats.
- Identify inconsistencies in the dataset.
- Validate numerical and date-related values.
- Apply appropriate cleaning techniques where required.
- Export the cleaned dataset for further analysis.

**Tools & Technologies:**
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Microsoft Excel

**Dataset Overview:**
- Total Records: 1,200
- Total Columns: 14
- Missing CouponCode values: 309
- Duplicate records: None identified

**Outcome:**  
Successfully examined and validated the dataset, documented data quality issues, and prepared a structured dataset for subsequent analysis.

### 2. Project 2 – Exploratory Data Analysis (EDA)

**Objective:**  
To explore the cleaned dataset, identify patterns and trends, analyze statistical information, and extract meaningful insights.

**Description:**  
Exploratory Data Analysis involves understanding the characteristics of a dataset through statistical analysis and visualizations. This project builds upon the data preparation work completed in Project 1.

**Key Tasks:**

  - Mean

- Analyze data distributions.
- Identify trends and patterns.
- Examine relationships between variables.
- Detect and investigate potential outliers.
- Create meaningful data visualizations.
- Summarize key findings and observations.

**Tools & Technologies:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Microsoft Excel

**Outcome:**  
Performed exploratory analysis to understand the dataset, identify important trends, examine outliers, and communicate findings through statistical summaries and visualizations.

### 3. Project 3 – SQL Data Analysis

**Objective:**  
To perform structured data analysis using SQL and extract meaningful information from an e-commerce dataset.

**Description:**  
This project focuses on applying SQL queries to analyze e-commerce order data. PostgreSQL was used to create and manage the database, import the dataset, and perform analytical queries.

**Database Information:**
- Database Name: `DecodeLabs_Project_3`
- Table Name: `orders`
- Database Management System: PostgreSQL
- Interface: pgAdmin 4
- Dataset: E-commerce Orders Dataset

**Key Tasks:**
- Create a PostgreSQL database and table.
- Import cleaned dataset into PostgreSQL.
- Retrieve records using SELECT statements.
- Filter data using WHERE conditions.
- Sort records using ORDER BY.
- Group data using GROUP BY.
- Perform aggregations using:
  - COUNT()
  - SUM()
  - AVG()
- Apply HAVING conditions.
- Analyze orders, products, payment methods, and order statuses.
- Explore customer and referral-source information.
- Perform date-based analysis.
- Extract useful information through SQL queries.

**Tools & Technologies:**
- PostgreSQL
- pgAdmin 4
- SQL

**Outcome:**  
Successfully used SQL to retrieve, filter, group, and summarize e-commerce data, demonstrating practical database querying and analytical skills.
